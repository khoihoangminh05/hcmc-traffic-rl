One-off batch scripts behind `.docs/AUDIT_SIM.md` (C1 and M items). They use absolute sol1 paths under
`/mnt/data8tb/minhkhoi/hcmc-traffic-rl/diag_v6` and are kept here as the record of how each number was made.
`cal12b.sh <mode> ...` runs `cal12b.py` (modes: ref, sweep, search2, rescore).
